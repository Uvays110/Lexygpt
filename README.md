# Kadro — сайт ИИ-сервиса для фото, видео и озвучки

Готовый сайт онлайн-сервиса генерации контента с помощью нейросетей: витрина с трендами и фотосетами,
каталог ИИ-моделей, студия генерации, тарифы, партнёрская программа и справка.

По структуре и возможностям сайт повторяет популярные ИИ-агрегаторы, но бренд, тексты, логотип и
оформление — свои. **Kadro** — временное название: оно меняется в одном файле (см. «Свой бренд»).

> Чужие логотипы, тексты, фотографии и реквизиты в проект не копировались — используйте только свой
> контент или материалы, на которые у вас есть права.

## Что внутри

**Страницы**

| Адрес | Что там |
| --- | --- |
| `/` | Главная: сторис, быстрый старт, тренды, промо-баннеры, видео-пресеты, идеи, фотосеты, рефералка, модели, эффекты |
| `/playground/{type}/{model}` | Студия генерации: выбор модели, формат, длительность/голос, количество, фото-референсы, история |
| `/trends`, `/sets`, `/prompts`, `/effects`, `/models` | Каталоги с фильтрами (категория сохраняется в адресе) и поиском |
| `/pricing` | Тарифы: ₽/$, ползунок пакета, сравнение, «что входит», FAQ |
| `/partner` | Партнёрская программа с калькулятором дохода и копированием ссылки |
| `/faq`, `/history`, `/terms`, `/privacy` | Вопросы и ответы, история генераций, шаблоны документов |

**Возможности**

- Тёмный дизайн, адаптив под телефоны (нижняя панель навигации), анимации без тяжёлых библиотек.
- Поиск по всему сайту — кнопка с лупой или `Ctrl/⌘ + K`.
- Реферальные ссылки: переход по `/?ref=КОД` сохраняет код пригласившего в cookie `ref`.
- Генерация через API-маршрут: в демо-режиме работает сразу, с ключом fal.ai — по-настоящему.
- SEO: метатеги, Open Graph-картинка, `sitemap.xml`, `robots.txt`, манифест для «добавить на экран».

## Быстрый старт

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшен-сборка:

```bash
npm run build
npm start
```

Проще всего опубликовать на [Vercel](https://vercel.com/new): импортируйте репозиторий, укажите переменные
окружения из `.env.example` — и сайт готов. Подойдёт и любой хостинг с Node.js.

## Свой бренд

| Что поменять | Где |
| --- | --- |
| Название, описание, ссылки на поддержку и ботов, проценты партнёрки, реквизиты | `src/config/site.ts` |
| Цвета (акцентный, фоны, текст) | `src/app/globals.css`, блок `:root` |
| Логотип | `src/components/ui/Logo.tsx` и иконка `src/app/icon.svg` |
| Картинка для соцсетей | `public/og.png` (1200×630) |
| Модели, цены в токенах | `src/data/models.ts` |
| Тренды, пресеты, идеи, фотосеты, эффекты, сторис | `src/data/catalog.ts` |
| Тарифы | `src/data/pricing.ts` |
| Вопросы и ответы | `src/data/faq.ts` |

**Свои фото и видео на карточках.** Пока у карточки нет превью, рисуется генеративная обложка. Положите файл
в `public/` (например, `public/trends/waltz.mp4`) и укажите его у карточки: `video: '/trends/waltz.mp4'` или
`image: '/trends/waltz.jpg'`.

Укажите в переменной `NEXT_PUBLIC_SITE_URL` адрес сайта — от него строятся canonical-ссылки и `sitemap.xml`.

## Генерация: демо и настоящие модели

По умолчанию сайт работает в **демо-режиме**: весь цикл генерации (поле ввода → загрузка → результат →
история) работает, но вместо настоящих картинок, видео и аудио отдаются заглушки с пометкой «Демо».

Чтобы генерировать по-настоящему через [fal.ai](https://fal.ai):

1. Получите ключ в личном кабинете fal.ai и добавьте его в переменную `FAL_KEY` (локально — в файл
   `.env.local`, на Vercel — в настройках проекта).
2. В `src/data/models.ts` укажите у нужных моделей поле `fal`:

   ```ts
   fal: { endpoint: 'fal-ai/nano-banana-pro', editEndpoint: 'fal-ai/nano-banana-pro/edit' },
   ```

   Пример уже стоит у Nano Banana Pro. ID и параметры у каждой модели свои — **сверьте их на странице модели
   на fal.ai** и при необходимости добавьте параметры в `fal.input`. Модели без `fal` остаются в демо-режиме.

Как это устроено: сервер ставит задачу в очередь fal.ai, браузер раз в 2,5 с спрашивает статус у
`/api/generate/status`, а сервер забирает результат. Ключ остаётся на сервере — браузер получает только
подписанный токен задачи. Логика — в `src/lib/generation/`.

> ⚠️ **Перед включением ключа** добавьте авторизацию и баланс токенов пользователей. Сейчас есть только простой
> лимит запросов с одного IP (`GENERATION_RATE_LIMIT_PER_HOUR`, по умолчанию 20 в час) — без входа в аккаунт
> любой посетитель сможет тратить ваши кредиты.

## Что нужно доделать для запуска бизнеса

Сайт закрывает всю витрину и интерфейс. Серверную часть сервиса нужно подключить отдельно:

- **Авторизация** (Telegram, Google, VK ID, почта) — сейчас окно входа показывает демо-сообщение.
- **Аккаунты и баланс токенов** — база данных, списание токенов за генерацию, история на сервере
  (сейчас история хранится в браузере).
- **Оплата и подписки** — например, ЮKassa, CloudPayments или Stripe; кнопки тарифов ведут на вход.
- **Начисление реферальных бонусов** — cookie `ref` уже сохраняется, её нужно считывать при регистрации и оплате.
- **Юридические документы** — `/terms` и `/privacy` содержат шаблоны с пометками `[…]`; замените их документами,
  проверенными юристом, и заполните реквизиты в `src/config/site.ts`.
- По желанию: другие языки, админ-панель для карточек каталога.

## Структура проекта

```
src/
  app/                    страницы (App Router) и API
    (site)/               страницы с подвалом: главная, каталоги, тарифы, партнёрка…
    playground/           студия генерации (без подвала)
    api/generate/         постановка задачи и проверка статуса
    api/demo/             заглушки демо-режима (SVG, анимированный SVG, WAV)
  components/             интерфейс: layout, home, catalog, studio, pricing, partner, ui…
  config/site.ts          настройки бренда
  data/                   контент: модели, каталог, тарифы, FAQ, поиск
  lib/                    утилиты: генерация, история, рефералка, хранилище
public/og.png             картинка для соцсетей
```

Стек: Next.js 16 (App Router), React 19, TypeScript, CSS-модули, иконки lucide-react, шрифты Unbounded и Manrope
(подключены пакетами `@fontsource`, без внешних запросов).
